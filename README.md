# PulseVault

A watch-only portfolio dashboard for Ethereum-compatible addresses across PulseChain and Ethereum. No private keys, seed phrases, or transaction signing.

## Address privacy

Wallet addresses entered by a user are stored only in that browser's local storage. Never add real wallet addresses to source code, fixtures, screenshots, logs, commits, issues, or other repository content.

## Development

```bash
npm install
npm run dev
```

The development server listens on the local network so it can be opened from a phone on the same Wi-Fi network.
